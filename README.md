# 灵台·观己｜轻量 Web MVP v2

**作者：王润圆，昆明医科大学硕士**

> 一个纯前端、轻量的自我健康观察与资料整理工具。

本次小修
- “最近事件”不再取最后录入的一条；只有时间能可靠比较时才按真实日历顺序判断。
- 年龄、年份、人生阶段等混合写法不会被强行混排；无法可靠比较时保持录入顺序，并使用中性故事表达。
- 时间输入框给出轻量格式提示，不强制填写完整日期。
- 其余技术栈、页面结构、隐私模式、PNG 和二维码流程保持不变。

使用方法
1. 解压后打开本文件夹里的 index.html；也可以把整个文件夹放到任意静态网页托管服务。
2. 填写观察资料和时间轴后生成观己报告，可导出高清 PNG 长图。
3. 数据只保存在当前浏览器的 localStorage，不上传、不跨设备同步。“清空本地记录”会删除本浏览器中的全部本地记录，且不可撤销。

时间填写建议
如希望系统可靠比较日历先后，推荐统一写成 2025、2025-06 或 2025-06-15。年龄和人生阶段仍可填写，但不会与年份强行排序。

二维码
当前二维码只包含项目首页：https://lingtai-guanji.vercel.app/
它不包含姓名、健康记录或其他个人数据。以后若部署到新的正式首页，请只修改 js/config.js 中的 PROJECT_HOME_URL。

边界
本工具用于自我观察、资料整理和专业沟通辅助，不用于诊断、治疗、用药或补剂处方。如有持续不适或健康风险，请咨询医生、营养师或其他合适的专业人员。

验证说明
已通过人类指定 A–D 场景、核心回归、真实 Chromium、移动/桌面长 PNG、二维码内容等价检查、浏览器本地保存与恢复、恶意文本/XSS 和零外部网络请求检查。尚未验证实体手机摄像头扫码、不同手机系统的保存弹窗和打印输出。
