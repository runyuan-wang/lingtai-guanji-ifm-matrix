# 灵台 · 观己

一个手机优先的“一题一页”自我观察问卷。用户回答 11 个轻量问题，可选填写昵称，完成后得到一份本地生成的中文观己报告，并可导出 PNG 长图。

## 使用

直接打开 `index.html`，或将整个目录放在任意静态网页托管服务中。问卷答案和当前进度只保存在浏览器 `localStorage`，不会上传或跨设备同步。

报告二维码只包含公开项目首页：<https://runyuan-wang.github.io/lingtai-guanji-ifm-matrix/>。

## 问卷插画

欢迎页与十二个逐题页面使用 `assets/illustrations/` 中的十张本地透明 PNG 作为装饰图，图片位于标题上方，加载失败时自动隐藏，不影响作答与导航。首题复用欢迎图；昵称页复用欢迎图，自由记录页复用精力图；生活变化与压力图按原稿保持相同。插画不会加入报告或导出的 PNG。

## 观察矩阵

报告会把真实选择的答案按 `js/matrix.js` 中的固定规则整理为七个 IFM 功能节点与中心 MES（心理 · 情绪 · 精神）。节点计数只是本次记录线索的数量：0 条为“未记录”，1–2 条为“有记录”，3 条及以上为“记录较多”。每张有记录的卡片最多展示三条真实来源选项。

正常 / 无明显问题、否定或跳过的选择不增加线索数；药物与补充剂只作为背景记录。自由文字不会被关键词推断，没有问卷依据的节点保持“未记录”。矩阵不涉及健康评分、疾病风险、严重程度、诊断或治疗建议，并会包含在导出的 PNG 长图中。

## 分析与生活方式建议

`js/guidance.js` 将旧版的简单节点分析和五类生活方式建议适配到当前问卷：只根据已填写的固定选项选择保守文案，提供睡眠与休息、运动与活动、营养与水分、压力调适、人际与支持的一般建议。正常、跳过和留空不会被改写为疾病或问题；不生成药物、补充剂剂量、化验或临床推断。

## 边界

本问卷及结果仅供参考，不构成医学诊断、治疗或用药建议。如需详细评估或个体化建议，请咨询医生或相关专业人士。填写内容只保存在当前浏览器中。

## 依赖

保留项目内随附的 `vendor/html2canvas.min.js` 与 `vendor/qrcode.js`，没有新增第三方依赖或远程资源。
